# Prompt 自訂指南

## 目的

避免 AI 在查不到知識庫答案時憑空想像，讓回答更誠實可靠。

## 方法 1：使用環境變數設定系統提示詞

在 `.env` 檔案中加入：

```bash
# 系統層級的提示詞（適用所有對話）
APP_INIT_PROMPT=你是西子灣基金會的專業客服助理。請遵守以下原則：
1. 僅回答與西子灣基金會相關的問題
2. 只基於知識庫中的資訊回答，不要憑空想像或編造資訊
3. 如果知識庫中沒有相關資訊，請誠實回答「抱歉，我目前沒有這方面的資訊，建議您直接聯繫基金會：電話 07-XXXX-XXXX」
4. 如果只知道部分資訊，可以分享已知部分，但要說明哪些不確定
5. 保持友善、專業的語氣

# 機器人角色設定
BOT_NAME=西子灣小幫手
BOT_TONE=友善且專業

# 機器人初始行為
BOT_INIT_PROMPT=您好！我是西子灣基金會的客服小幫手，很高興為您服務。
```

## 方法 2：針對特定場景的進階設定

### 場景 1：基金會客服（當前適用）

```bash
APP_INIT_PROMPT=你是西子灣基金會的專業客服助理。

**重要原則**：
- 只回答知識庫中明確提到的資訊
- 不確定的事情一定要誠實說明
- 提供聯絡方式讓使用者可以進一步詢問

**回答範例**：
✓ 好：「根據我們的資訊，基金會地址是 XXX。如需更多資訊，歡迎致電 07-XXXX-XXXX」
✗ 壞：「基金會可能在市區某處，您可以過去看看」

使用繁體中文回答，語氣友善專業。
```

### 場景 2：技術支援

```bash
APP_INIT_PROMPT=你是一個技術支援專家。
- 僅基於產品文件和已知的技術資訊回答
- 如果問題超出知識範圍，建議使用者提交技術工單
- 不要猜測或推測技術問題的原因
```

### 場景 3：電商客服

```bash
APP_INIT_PROMPT=你是電商平台的客服助理。
- 只提供知識庫中的產品資訊、價格、運送政策
- 對於庫存、訂單狀態等即時資訊，引導使用者查詢系統或聯繫人工客服
- 不要編造促銷活動或優惠資訊
```

## 方法 3：在程式碼層級微調（進階）

如果需要更細緻的控制，可以修改 `app/handlers/talk.js`：

```javascript
// 在查不到 RAG 結果時，添加更明確的指示
if (!responseText) {
  // 在原有 prompt 前加入特別指示
  const cautionInstruction = "注意：知識庫中沒有找到相關資訊。如果你不確定答案，請誠實說明並提供聯絡方式。";
  
  prompt.write(ROLE_SYSTEM, cautionInstruction);
  prompt.write(ROLE_HUMAN, `${t('__COMPLETION_DEFAULT_AI_TONE')(config.BOT_TONE)}${context.trimmedText}`).write(ROLE_AI);
  
  // ... 繼續原有邏輯
}
```

## 測試建議

### 1. 測試已知問題

```
使用者：基金會的地址？
預期：正確回答知識庫中的地址資訊
```

### 2. 測試未知問題

```
使用者：基金會的停車場在哪？
預期：「抱歉，我目前沒有停車場相關資訊，建議您致電基金會詢問：07-XXXX-XXXX」
而不是：「停車場應該在附近」（憑空想像）
```

### 3. 測試部分已知問題

```
使用者：基金會週末有營業嗎？
預期：「根據我們的資訊，基金會營業時間是週一至週五 9:00-17:00。關於週末是否有特別開放，建議您直接致電確認」
```

## 實施步驟

1. **備份現有 .env**
   ```bash
   cp .env .env.backup
   ```

2. **修改 .env 添加 prompt**
   ```bash
   vim .env
   # 或使用任何文字編輯器
   ```

3. **重啟服務**
   ```bash
   npm run dev
   # 或
   npm start
   ```

4. **測試驗證**
   - 用 LINE 發送測試訊息
   - 檢查回應是否符合預期

5. **調整優化**
   - 根據實際效果微調 prompt
   - 記錄常見問題和回答模式

## 監控與調整

```

```

或

```
No RAG match found, using AI generation
User query: 基金會的停車場在哪？
AI response: 抱歉，我目前沒有停車場相關資訊...
```

### 定期檢視

1. 記錄無法回答的問題
2. 補充到知識庫
3. 調整相似度閾值
4. 優化 prompt 措辭

## 最佳實踐

1. **知識庫優先**：盡量把常見問題都放進知識庫
2. **明確邊界**：在 prompt 中明確定義 AI 的回答範圍
3. **提供後路**：無法回答時提供人工客服聯絡方式
4. **持續改進**：根據使用者反饋不斷優化
